# 给小板添加自定义角色

一句描述或一张参考图可以用来确定角色造型和动作方向。已有完整角色包时，可以直接安装到小板。装好后，从「角色图鉴」可以找到、试播和切换。完整显示固件的图鉴使用 role1 ZIP 角色包。

## 试试这三句话

> 帮我在小板上装一个 Pocket Bot 示例角色。我想在图鉴里看看它怎么动。

> 用我发的图做一只奶油色小猫。平时眨眼，点它就挥爪，工作完成时高兴地跳一下。先给我看电脑上的预览。

> 帮我把下载目录里的「小企鹅.zip」装到客厅的小板上，再确认图鉴里找得到。

## 先体验 Pocket Bot

Pocket Bot 是用来体验打包、安装和图鉴播放的技术样例。它的 12 个互动复用了少量姿态，动作表现尚未达到完整角色交付标准。让 Agent 调用 `desk_create_role_example`，把 `destination` 设为电脑上已有目录里的一个新 ZIP 文件绝对路径。工具返回可安装的 `path` 和角色 ID `user-pocket-bot`。这个步骤无需小板在线。

如果只想看看样例，可以把 ZIP 留在电脑上。想装上小板时，按下面的步骤继续。

## 安装到小板

1. 用 `desk_check_role(source=...)` 在电脑上检查角色包。填写 ZIP 的绝对路径，无需连接小板。工具会核对必需资源、文件名及大小写、角色 ID、动作数量和命名规则，并检查帧和时间轴。返回 `invalid` 时按原因修正，返回 `valid` 时可看到角色 ID、资源和动作列表。可以先用 `desk_list_role_sources(directory=...)` 找候选包。
2. 用 `desk_list_devices` 确认目标小板，再用 `desk_status` 确认已连接。多台小板时，使用目标小板的 `device_id`。
3. 用 `desk_install_role` 安装，把 ZIP 的本机绝对路径填入 `source`。安装器会重新校验本次要传的文件，通过后才开始写卡。小板再校验并启用角色。使用与卡上已有角色不同的 ID 会添加一项。同一个 ID 会更新已有角色。
4. 安装返回 `ready` 后，用 `desk_list_roles` 确认角色 ID 在列表里。用户可以在小板上打开「角色图鉴」。Agent 可以用 `desk_set_view(page="roles")` 打开图鉴，再按需用 `desk_role_preview` 试播。试播需要固件支持 `role_preview`，结束后会返回图鉴并恢复试播前的角色。

小板离线时可以先把角色包准备好。安装报错时，保留本机 ZIP，按回执检查连接、储存卡或角色包。传输结果未确认时，先查设备状态和角色列表。把普通图片或 ZIP 当成文件传到卡上，无法完成角色登记。

完整显示固件只接受 role1。安装返回 `role1_required` 时，准备完整的 role1 包再传。从储存卡恢复时，可以用备份的角色版本目录作为 `source`，恢复后会沿用备份中的完成动作。

## 完整角色交付标准

完整角色要能在图鉴中识别、在屏幕上展示，也要能响应速度变化和互动。系统决定何时播放，各角色用自己的姿态和节奏表达同一个动作的含义。

- **图鉴与场景。** 提供稳定的角色 ID、图鉴显示名、独立的透明头像和可分开使用的背景。背景可复用。按 320 × 240 画面给读数、趋势和消息留出空间。提供每组动作的帧顺序、节奏和对齐位置，切换时保持位置连贯。
- **五档速度动作。** 从慢到快提供五个可独立循环的动作。检查首尾衔接和相邻档位的强度差异。
- **独立爆气。** 提供可叠加在当前动作上的独立效果。检查它单独触发和结束时，当前档位的动作保持连续。
- **待机表情。** 提供 3～9 种可辨的表情，指定一种默认表情。待机表情和互动动作分别验收，可以复用画面。
- **基础互动。** 逐一验收以下 12 个动作，确保含义可辨。其余 18 个动作可以按需扩展。

| 用途 | 动作 |
| --- | --- |
| 日常状态 | 轻呼吸 `idle_breathe`、眨眼 `idle_blink`、醒来 `wake`、专注 `focus` |
| 等待与引导 | 举手 `raise_hand`、等回复 `wait_reply`、请求确认 `show_approval`、指向列表 `point_list` |
| 结果与互动 | 小庆祝 `celebrate_small`、受惊 `startled`、被触碰 `touched`、断开连接 `disconnected` |

## 给制作角色的 Agent

从用户的描述或参考图出发，先做一张 4∶3 构图和一段最能体现角色性格的循环动作预览。缩到 320 × 240 检查辨识度和读数空间，再完成其余素材。用户只要求看预览时，可以先交付这个阶段。

示例源码 `deskpet_platform.role_example` 随 Python 包安装，可复制到工作目录作为起点。修改 `IDENTITY`（例如 `user-cream-cat`）、`NAME` 和 `example_files()` 中的素材。可以把绘制的姿态替换为用 Pillow 读取的透明 PNG，用 `motion_cel`、`motion_file` 和 `interaction_files` 沿用示例编码。保留示例的打包校验入口。用同一个 Python 环境导入副本并调用 `create_role_example`，输出到一个新的 ZIP 路径。生成图鉴预览时，以实际绘进图鉴行的文字为准。

| 素材 | 制作约定 |
| --- | --- |
| 角色名与 ID | 图鉴名写入清单并绘到图鉴行中。ID 以 `user-` 开头，后接小写字母或数字，可继续用小写字母、数字和连字符，含前缀最多 48 字符。 |
| 待机、速度和爆气 | 184 × 192 透明帧。先放五个由慢到快的动作序列，再放 3～9 张待机帧，首帧为默认表情，最后放独立爆气效果帧，合计最多 128 帧。爆气效果会叠在角色后面。 |
| 互动 | 176 × 160 透明帧，与运动帧使用同一角色位置。示例从运动画布裁取 `(4, 25, 180, 185)`。按上表的固定 ID 编排全部 12 个动作。 |
| 背景 | 屏幕取中间的 320 × 240。背景编码画布为 336 × 240，左右各留 8 像素，可用相邻边缘补齐。 |
| 图鉴行 | 320 × 68 的头像与角色名。使用所选文字的可用字体，给右侧固件的选中标记留空间。 |

用角色交付标准逐项验收预览，再用 `desk_check_role` 校验角色包。动作含义是否清楚、相邻档位差异是否看得出来，需要看实际播放。用户要求装到小板时，继续完成安装，核对图鉴、默认待机、五档、爆气和互动。
