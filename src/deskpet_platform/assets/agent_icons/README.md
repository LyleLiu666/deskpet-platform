# Agent marks

The five PNG files are rasterized, unmodified monochrome icons from
[`@lobehub/icons-static-svg` 1.97.0](https://github.com/lobehub/lobe-icons),
licensed under the accompanying MIT license. Names map directly to the source
files: `openai.svg`, `claudecode.svg`, `workbuddy.svg`, `antigravity.svg`, and
`opencode.svg`. `chatgpt.png` uses the `openai.svg` knot for Codex reminders.
Their marks remain the property of their respective owners.
